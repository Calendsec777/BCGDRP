# Source Data

Underlying values for every main-text figure, main-text table and supplementary display item.

**On filenames.** Several prefixes are historical. The manuscript was reorganised from five figures to
seven, and the files kept their original names so that the analysis scripts and released figure
builders continue to reference the same paths. The prefix therefore does
not track the current figure number, and the mapping below is authoritative. For example
`Fig5_wetlab_ic50_fits.csv` supplies Figure 7 and `Fig4_breast_heatmap_values.csv` supplies Figure 6.

Files are generated by the scripts in `experiments/analysis/` and consumed by the figure builders
in `figures/`. The mapping below identifies the article panel or table supplied by each file.

---

## Figure 1. Study design and benchmark

## Figure 7. Experimental follow-up

All CCK-8 measurements come from assays recorded on 2 August 2026. The tidy replicate table below is
the canonical released input. The original laboratory workbooks contain unrelated laboratory context
and are not distributed. Fits can be regenerated with `experiments/analysis/dose.py`.

| file | supplies |
|---|---|
| `Fig5_nomination_baseline_audit.csv` | the 16 candidates with no GDSC2 annotation for 5637, with the mean observed response of each compound over the model-visible cell lines and over the other held-out urinary tract cell lines, and the rank each rule assigns |
| `Fig5_missing_candidate_predictions.csv` | raw model output for every held-out urinary tract cell line paired with a compound carrying no GDSC2 response, including the 5637-Daporinad prediction of -3.127350 reported in the text. This is the provenance of the nomination |
| `Fig5_wetlab_replicates.csv` | replicate-level CCK-8 measurements for all seven dose-response curves, three technical replicate wells at each of nine or ten concentrations |
| `Fig5_wetlab_ic50_fits.csv` | four-parameter logistic fit parameters, replicate-level coefficient of determination, and bootstrap confidence intervals for every curve. Also supplies the wet-lab table in the main text |
| `calibration_shrinkage.csv` | the fitted compression of cell-specific deviations, which is the mechanism behind the potency errors |

## Harmonisation record

`CTRPv2_external_harmonization.json` records how CTRPv2 records were matched to GDSC2 compounds and
cell lines, including the identifiers that failed to match and the reason. It is the provenance for
the shared-pair counts used in the cross-screen analysis.
